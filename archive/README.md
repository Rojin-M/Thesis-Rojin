# Archived research material

This directory holds exploratory experiments, older configs, result folders, tests, and implementation modules that are no longer part of the active thesis narrative. They are preserved for provenance and possible recovery, but they are intentionally not part of the public continuation path.

## Included here

- legacy configs in `archive/legacy-configs/`
- legacy experiment scripts in `archive/legacy-experiments/`
- legacy result folders in `archive/legacy-results/`
- legacy tests in `archive/legacy-tests/`
- legacy training modules in `archive/legacy-training/`
- older experimental notes and run artifacts not needed for the current project story

## When to use the archive

Use this directory only when:

- you need earlier experiment provenance,
- you want to recover a previously tested config,
- or you want to inspect a rejected idea without polluting the active route.

Do not add new experiments here. New work should be added to the active public path only after it changes the project story or becomes a reproducible evidence bundle.
