## Recommended continuation workflow

1. Read the storyline and model journey.
2. Choose one active config to evaluate.
3. Run the relevant production path.
4. Record the result in a dated folder under `results/`.
5. Add a short README plus checksum evidence.
6. Update the evidence index only if the result meaningfully changes the project decision.

## Good next experiments

The next worthwhile work is one of:

- larger fresh classifier validation for the selected comparator,
- tighter calibration or event-level audit for the chosen model,
- an explicit multi-sector or contamination check,
- or a new freeze of the best performing active config.

## Do not do this again

Do not keep adding one-off configs and one-off result folders without placing them into a dated and indexed public evidence bundle. The clean repo is meant to stay navigable and defensible.

## Keep in mind

- The public story is not a claim of a new planet.
- File heavy data and outputs locally.
- Only compact, frozen evidence should be committed.
- Archive older experiments, do not keep them in the active path.
